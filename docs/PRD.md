# 《黄鹤楼积木：筑梦江城》产品方案（完整版）

> 状态：立项文档 · 作者：产品团队 · 评审意见见 [REVIEW.md](./REVIEW.md) · 拆解任务见 [BACKLOG.md](./BACKLOG.md)
> 本文为产品原始方案，技术核实与修订建议在 REVIEW.md，不直接改动原文。

**一句话定位**
一款基于 Bevy 引擎的轻量级 3D 积木搭建游戏，以武汉黄鹤楼为核心主题，玩家通过放置模块化积木还原、自由创造或挑战重建这座千年名楼，融合"精准复原 + 自由创造 + 文化沉浸"的核心体验。

---

### 1. 产品愿景与核心价值

- **愿景**：让玩家在数字世界亲手"重建"黄鹤楼，感受中国古建筑的韵律与智慧，同时享受积木搭建的纯粹乐趣。
- **核心价值主张**：
  - 文化载体：真实还原黄鹤楼建筑形制与文化意象。
  - 创作自由：从严格蓝图到完全自由搭建的光谱体验。
  - 技术轻量：Rust + Bevy 带来高性能、可扩展、易维护的现代引擎体验。
- **目标用户**：
  - 主：18-35 岁喜欢建造类游戏、对中国传统文化有好感的玩家。
  - 次：建筑/设计爱好者、教育场景（亲子/课堂）、武汉本地文化传播。

**产品逻辑自洽原则**
所有玩法必须服务于"搭建过程本身就是核心乐趣"，任何附加系统（挑战、收集、社交）都不能打断或取代"放置积木"的心流。进度、奖励与建筑完成度强绑定，避免无意义的数值膨胀。

---

### 2. 核心玩法循环（Core Loop）

1. **选择模式** → 进入场景
2. **观察蓝图/自由构思** → 选积木
3. **精准放置 / 自由创造** → 即时反馈（吸附、高亮、音效）
4. **阶段性完成** → 解锁新积木/视角/成就
5. **整体完成 / 分享 / 挑战下一关** → 回到1

**三大核心模式（产品逻辑闭环）**

| 模式       | 目标                  | 核心机制                     | 完成条件与奖励                  | 自洽逻辑                     |
|------------|-----------------------|------------------------------|---------------------------------|------------------------------|
| 蓝图复原   | 精准还原官方黄鹤楼   | 半透明幽灵蓝图 + 严格吸附   | 完成度≥95% 解锁完整外观与成就  | 教育+成就感，强制学习结构    |
| 自由创造   | 无限搭建              | 无蓝图限制，支持多楼层扩展  | 无强制，可保存分享             | 纯创作出口，防止蓝图疲劳     |
| 挑战模式   | 限时/限料/特殊规则    | 倒计时、材料配额、风向等    | 星级评价 + 稀有积木            | 增加重玩价值与技巧深度       |

### 3. 功能模块核心拆解

**3.1 积木系统（核心资产）**
- 积木分类（按真实建筑结构拆解）：
  - 基础：台基、柱础、红柱、梁枋
  - 结构：斗拱组（可组合）、楼板、回廊栏杆
  - 屋顶：琉璃瓦片、飞檐翘角、宝顶、脊兽
  - 装饰：窗棂、匾额、铜鹤、灯笼
  - 特殊：可活动部件（可旋转的鹤、可开合窗）
- 吸附与对齐规则：网格吸附 + 智能磁吸（相同类型优先）+ 旋转90°/45°限制（保证古建对称美学）。
- 材质与变体：黄琉璃、朱红漆、青石、木纹等，支持染色系统（后期）。

**3.2 场景与相机系统**
- 固定主场景：蛇山 + 长江远景 + 可切换昼夜/天气。
- 相机：轨道相机（默认）+ 第一人称自由飞行 + 固定观赏视角（完成时自动切换）。
- 辅助工具：蓝图透明度调节、剖面视图、测量尺、撤销/重做（至少20步）。

**3.3 引导与教学**
- 新手强制教程：前三步强制蓝图模式，教学吸附、旋转、删除。
- 智能提示：放置错误时柔和高亮正确位置；长时间停顿弹出结构知识卡片（可选关闭）。

**3.4 进度与收集**
- 建筑完成度百分比 + 结构正确率。
- 收集系统：完成蓝图解锁"真实部件图鉴"与文化小知识。
- 成就：首次完成、限时通关、无错误完成、自由创造达到一定体积等。

**3.5 保存与分享**
- 本地存档（JSON + 二进制压缩）。
- 导出截图 / 短视频（内置录制）/ 分享码（后期可做云端）。

### 4. 技术实现规约（Bevy 专属）

**引擎与版本**
- Bevy ≥ 0.19（当前稳定推荐）
- 物理：avian3d（推荐）或 bevy_rapier3d
- 主要依赖：bevy_egui / bevy_inspector_egui（调试）、bevy_mod_picking 或内置 picking、serde + bincode（存档）

**核心架构规约**
1. **ECS 优先**：所有积木、蓝图幽灵、玩家操作均以 Entity + Component 表达。禁止大范围全局可变状态。
2. **数据驱动**：积木定义全部走 `.ron` 或 `.toml` 配置文件（ID、网格、材质、吸附规则、文化描述）。
3. **分块与性能**：
   - 世界采用稀疏 HashMap 或 Octree 管理已放置积木。
   - 网格生成采用"脏标记 + 异步贪婪网格化"（参考 block-mesh / 自研）。
   - 渲染层使用 Bevy 的 GPU-driven 能力，严格控制每帧新增/销毁实体数量。
4. **放置逻辑规约**：
   - 射线检测 → 候选网格位置 → 合法性校验（重叠、支撑、蓝图匹配）→ 生成 Entity。
   - 所有放置必须可撤销，使用 Command 模式记录操作历史。
5. **资源加载**：
   - 积木模型统一 glTF，低面数优先（单个积木 ≤ 500 三角面）。
   - 使用 Bevy AssetServer + 热重载开发期支持。
6. **存档格式**：版本号 + 世界种子/模式 + 积木列表（位置、旋转、ID、自定义属性）。
7. **平台目标**：优先 Desktop（Windows/macOS/Linux），后期可考虑 Web（WebGPU）与移动端简化版。

**代码组织建议**
```
src/
├── main.rs
├── game_state.rs          # 状态机
├── building/
│   ├── voxel_or_modular.rs
│   ├── placement.rs
│   ├── blueprint.rs
│   └── meshing.rs
├── camera/
├── ui/
├── save/
└── resources/             # 配置与资产定义
```

### 5. 美术与音频规范

- **风格**：写实与 stylized 之间的"精致积木风"——保留黄鹤楼的飞檐曲线与比例，但积木边缘清晰、可识别。
- **色彩**：严格参考真实黄鹤楼（黄琉璃为主、朱红柱、白墙、青灰基座）。
- **比例**：以真实建筑 1:50~1:100 为参考，保证"一眼能认出是黄鹤楼"。
- **音频**：放置清脆木石碰撞声、完成时悠扬编钟/古琴、环境长江水声 + 风铃声。

### 6. 用户流程与体验自洽

**新玩家路径**
启动 → 简短过场（鹤飞过长江）→ 强制教程蓝图（基座→柱→一层屋顶）→ 完成首次小成就 → 开放自由模式与完整蓝图。

**老玩家路径**
主菜单直接进入自由创造或挑战列表，支持快速加载上次作品。

**防挫败设计**
- 蓝图模式允许"提示一次"按钮（消耗无惩罚）。
- 自由模式完全无失败状态。
- 任何时候可一键"重置到上一个检查点"。

---

### 7. 开发路线图（建议）

**Phase 0（2-3周）**：技术验证
- Bevy 空场景 + 基础轨道相机 + 单个可放置立方体积木 + 射线放置。

**Phase 1（MVP，6-8周）**
- 完整积木库（30-40种）
- 蓝图模式（简化版黄鹤楼）
- 基础UI、撤销、保存
- 完成度计算

**Phase 2（完整版，8-12周）**
- 自由创造 + 挑战模式
- 精美场景与昼夜
- 图鉴与成就
- 优化与打磨

**Phase 3（运营与扩展）**
- 创意工坊分享
- 额外主题包（滕王阁、岳阳楼等）
- 多语言与无障碍

---

### 8. 风险与产品自洽性检查清单

| 风险点               | 应对措施                              | 自洽性保证                     |
|----------------------|---------------------------------------|--------------------------------|
| 古建复杂度过高       | 分层解锁，先做简化结构再开放细节     | 玩家始终有可完成的阶段性目标   |
| 放置精度挫败         | 强吸附 + 幽灵提示 + 可关闭辅助       | 保持"搭建即乐趣"不被技术打断   |
| 性能（大量积木）     | 强制分块 + 异步网格 + 实例化渲染     | 保证60FPS下限体验              |
| 文化准确性争议       | 明确标注"艺术还原"，提供官方参考图   | 尊重历史但不追求考古级精确     |
| 内容消耗快           | 自由模式 + 挑战变体 + 后续主题包     | 核心循环可无限重复             |

---

### 9. 成功指标（产品层面）

- 新手教程完成率 ≥ 85%
- 首次完整蓝图完成率 ≥ 40%
- 平均单次会话时长 ≥ 25 分钟
- 自由创造作品保存率 ≥ 60%
- 玩家主动分享截图/视频比例可观
