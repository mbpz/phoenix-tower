### 已落实的几何

- 平面选中柱符号分别为 **72 / 52 / 44 / 44 / 44 / 36**。合计 292 是六个平面上的符号数，不代表整楼独立柱子数量。底层 R300 墙角圆弧已排除，不当作柱子。
- 主层标高 `0 / 12.300 / 19.400 / 26.000 / 32.600 m`，首个夹层 `6.000 m`。其余夹层、机房、水箱层尚未建。
- 首夹层“前厅上空”保留真实网格贯通孔洞；楼梯井、电梯井使用明确标为示意的矩形包络，尚无楼梯踏步或可行走碰撞体。
- 柱高是楼层间展示长度，柱半径 `0.3 m`、板厚 `0.24 m`、材质均为展示代理参数；外柱顶部可能悬空。外围线按数据中声明的轴线/栏杆参考线建立，不一概当作完成面板边。
- 结构网格 **12 个对象、20,380 个三角形**（不含文字/曲线求值几何）。按层合批柱体，拆层场景共享网格，未增加材质、物理、游戏依赖。

### 翼角必须保留的疑点

详见 `yellow-crane-eave-traces.json`。图内说明“标高为真高，但长度应按平面图斜长展开”，因此像素描线不能直接旋转复制为所有屋面。

1. 对称翼角四层右下标注暂读 `32.000 m`，与剖面/非对称变体 `30.420 m` 不一致；不得静默改字后称精确复刻。
2. 二层下檐对称 `17.220 m`、非对称 `17.200 m` 相差 20 mm；需要核对图纸修订或变体意图。
3. “檩条顶面升起曲线示意”和标明“不作放样用”的上部虚线不作为当前下檐轮廓；端帽未描取。`metric_points`、`roof_plan_mapping` 保持 `null`。
