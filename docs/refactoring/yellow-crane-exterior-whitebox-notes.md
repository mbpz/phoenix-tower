## 尚未通过，不能进入 M2 复制细化

1. 顶冠主/副屋面在第7版改为共用接缝的连续壳体（见后文）；与下层顶檐、脊帽的接触仍未验收，角部曲率和檐口轮廓仍不自然。
2. 第 5 版已恢复底层过渡带的矩形分格体量，但分格位置、构造性质和与屋檐交界的准确性仍未验收。
3. 各层屋面仍需独立平面核对，不能把同一层的缩放估计冻结为正确建筑形制。
4. 斗拱/檐口厚度与支承、山花/牌楼面板的主要外观体量尚缺；细部纹饰可留到 M2，但支承轮廓须先补。
5. 单对象封闭性不检查跨对象穿插、自交、可行走通路、材质 UV 或游戏性能。上述各项都未验收。
