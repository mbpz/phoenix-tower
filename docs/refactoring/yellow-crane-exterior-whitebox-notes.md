## 本轮模型及验证

独立场景 `HHL_Exterior_Whitebox_04`，本地文件 `.omx/references/yellow-crane/exterior-whitebox-04.blend`。
原有结构/分解/参考场景不删除；新建版本遇到文件或场景同名会拒绝覆盖。

- 32 个 mesh 对象，93,816 个三角面（研究模型，不是性能预算）。
- Blender 实际检查：逐对象非流形边与不一致绕向边均为 0；1,866 个连通壳体逐个检查带符号体积为正。
- 24 个纯 Python 测试通过：包含既有结构/檐口测试以及新增曲面封闭性、法向体积、无效输入、版本文件保护、单面反向/混合反向壳体、阶梯连续性、注入保存失败后的重试测试。
- 正面及斜视各渲染四轮。检查不等于精确复刻验收。
- `export_to_game=false` 是研究标记，**不是强制导出拦截器**；本轮未调用导出或改动游戏运行时。

## 尚未通过，不能进入 M2 复制细化

1. 顶冠四副屋面与主屋面的交界未裁剪，白模可见交叠；角部法线和尖部曲率仍不自然。
2. 底层屋盖上方的过渡带过于简单，未按立面恢复窗带与檐墙关系。
3. 各层屋面仍需独立平面核对，不能把同一层的缩放估计冻结为正确建筑形制。
4. 斗拱/檐口厚度与支承、山花/牌楼面板的主要外观体量尚缺；细部纹饰可留到 M2，但支承轮廓须先补。
5. 单对象封闭性不检查跨对象穿插、自交、可行走通路、材质 UV 或游戏性能。上述各项都未验收。

下一步先处理 1–4，再冻结 M1。原始图纸、本地 Blend 文件和含原图的叠加图不进入提交或游戏分发。
