## 剩余风险与下一步边界

1. **CJK 上游分词与持续诊断未消除**：已定位构造器与实际调用链，应用重复写入仅是部分开销。不得宣称日志量已定量下降（本次没有同条件 A/B），也不得直接吞 stderr。下一步需在独立范围验证 Parley/Bevy 上游修复或最小受控补丁，并覆盖中文断行、混合文本与性能。
2. **50k 渲染性能仍不足**：下一步要采集 CPU/GPU 帧耗时和绘制/阴影成本，再决定具体优化；当前样本不能判断 GPU、日志 I/O 或文本排版各占多少。50k 数据测试中撤销会重建占用索引，单次基准不保证大世界的交互尾延迟。
3. **跨平台仅配置就绪**：现有 CI 已扩为 Ubuntu/macOS/Windows 的 locked all-target 检查/无窗口测试/Clippy/fmt/Python 回归，补 Linux 系统库；本次未 push、未触发远端 CI，没有 Windows/Linux 实机 GPU 结果。
4. **人工与长时玩法未覆盖**：已增强真实挑战系统回归，但没有宣称完成全部真实蓝图人工通关、窗口输入/相机/音频/平台切换、长时重力和真实大世界联合作业验收。
5. **依赖和存档约束不变**：未新增或升级依赖，未改 `.ptw` v1；工具不发送保存按键、不覆盖存档槽。游戏自己的进度机制和截图目录仍属于编译时根目录，测试时不要手动操作窗口。
