# 人工验收清单（Playtest Checklist）

> 用途：B-04（Phase 0 验收）、B-14（MVP 验收）、B-22（完整版验收）的人工试玩清单。
> 全部为**需人工在真机上操作确认**的项；自动化验证项（单元测试/压力基准）已在对应 BACKLOG 条目记录。
> 环境：macOS / 本机 M1 · `cargo run` · 每项标注预期结果与操作路径。

## A. 启动与教程（对应 B-12 交付）

- [ ] 启动后自动进入**新手教程**，HUD 显示第 1 步引导（台基）
- [ ] 按引导放置大台基 → 自动推进到第 2 步（高柱，自动选中）
- [ ] 完成三步（大台基→高柱→重檐大梁）后提示"新手教程完成"，解锁自由模式
- [ ] 按 `N` 可跳过教程
- [ ] 按 `L` 切换英文界面，教程/面板/HUD 文案随动

## B. 蓝图复原（对应 B-08/B-09 交付）

- [ ] `M` 进入蓝图模式：半透明幽灵蓝图显示（黄鹤楼五层收分 331 格，含攒尖顶/八角/匾额）
- [ ] 选择台基放置：绿色幽灵 + 点击放置；完成度进度条增长
- [ ] 放置错误格：红色幽灵 + 呼吸脉冲（不依赖纯颜色）
- [ ] 完整搭建至 ≥95%：编钟音效 + "黄鹤楼复原完成"提示 + 成就解锁
- [ ] 面板"蓝图主题"下拉切换滕王阁/岳阳楼，幽灵蓝图随之重建

## C. 自由创造（对应 B-15 交付）

- [ ] `M` 切自由模式：任意位置放置（含多楼层堆叠）
- [ ] `R` 旋转 90°（梁枋横竖变化）；`X` 拆除模式点击移除
- [ ] `G` 重力测试：拆除一根柱子后测试，上部坍塌、显示存活率与星级
- [ ] 搭建 ≥ 30 块触发"广厦千万"成就

## D. 挑战模式（对应 B-16 交付）

- [ ] `C` 开始挑战（面板可选限时复原 300s / 极速复原 120s）：倒计时 + 材料配额（12 种）
- [ ] 配额耗尽后该积木无法放置（幽灵变红）
- [ ] 限时内完成 → 星级评价；超时 → 失败提示，C 重试
- [ ] 完成后图鉴解锁"鎏金宝顶"稀有标记

## E. 存档与分享（对应 B-11/B-23 交付）

- [ ] `F5` 保存 → `saves/slot1.ptw`；`F9` 读取还原（含旋转/堆叠）
- [ ] `F7` 分享导出 → `saves/share_<时间戳>.ptw`
- [ ] 面板"存档"Tab：列表显示 .ptw，点击加载；自定义路径导入
- [ ] `F2` 截图 → `saves/screenshot_*.png`（非黑帧）
- [ ] 重启游戏后 `F9` 读档仍可还原（存档跨启动）

## F. 图鉴与成就（对应 B-18 交付）

- [ ] 面板"图鉴"Tab：蓝图放置过的部件已解锁并显示文化描述
- [ ] "成就"Tab：完成/撤销等条件对应解锁；重启后仍保留（progress.json）

## G. 场景与表现（对应 B-13/B-19/B-20 交付）

- [ ] `T` 昼夜平滑过渡（天空/光照联动）
- [ ] 放置有碰撞音效（石/木分类）；完成有编钟；环境有江水+风铃
- [ ] HUD 显示 FPS/积木数；搭建 5000 块（压力模式）不卡顿

## H. 完整版验收补充（对应 B-22）

- [ ] 连续游玩 30 分钟无 panic / 无资源泄漏（观察内存）
- [ ] 全模式（教程/蓝图/自由/挑战）循环切换无状态错乱
- [ ] `PHOENIX_STRESS=50000 cargo run` 后 FPS 记录与 BACKLOG 基准一致
