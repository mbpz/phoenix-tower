# 江岸古建：Blender 可玩切片

## 边界与清理计划（实现前）
- 保留当前未提交风险修复，不升级 Bevy、不增加依赖、不修改存档 v1 或占格规则。
- Blender 负责可重建低多边形网格；Bevy 继续负责放置、撤销、保存、相机和物理。
- 模型使用一个 mesh/primitive、顶点颜色、以占格包围盒中心为原点、米制 Y-up；共享网格，不为每块导入场景树。
- 制作台基、朱柱、梁枋、斗拱、楼板和独立七格亭顶；保留未覆盖积木的程序化网格。高细节模型仅在 --riverside 启用，普通/压力模式保持轻量程序化资产。
- 新增显式 `--riverside` 可玩样板启动入口。仅在空世界初始化，不覆盖读档、压力测试或用户建筑；样板积木进入现有撤销历史。
- 样板采用江岸石台、远山、树木与水面，调整初始观察视角。装配反馈只改变独立视觉效果，不改变积木/碰撞体变换。
- 不进行 UI 框架迁移或通用资产框架重构；直接复用现有资源、系统、世界记录。

## 验证
1. 先运行现有 Rust 回归测试，再补样板占格无重叠、撤销/保存一致性及模型契约检查。
2. 实际调用本机 Blender，提交脚本、源场景、GLB 与生成清单；检查顶点颜色、primitive 数量、坐标/尺寸和面数预算。
3. 离线 fmt/check/test/clippy 与既有 Python 验证器回归。
4. 原生 Bevy 启动并截图；按微缩古建、轮廓层次、材质配色、江岸环境、交互可读性进行视觉判定。无外部参考图，不冒充像素级比对。

## 已知边界
- 这是单层可编辑建筑体验，不是完整关卡/新物理玩法。
- 顶点色资产无贴图下载；远景模型不参与建造占格。
- CJK shaping 上游警告与跨平台 GPU 验证仍单独跟踪。

## 接入时发现的两处边界修复
- 单格蓝图幽灵比实际积木的 x/z 原点偏半格；先补回归，再统一预览位置，不改实际占格。
- 自由编辑后打开蓝图，完成度可能沿用旧值；补模式开启时重算的回归，保留原完成事件语义。
