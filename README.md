# 黄鹤楼积木：筑梦江城（Phoenix Tower）

基于 **Rust + Bevy 0.19** 的轻量级 3D 积木搭建游戏：以武汉黄鹤楼为主题，玩家通过放置模块化积木**精准复原**、**自由创造**或**挑战重建**这座千年名楼。

> 状态：**Phase 0 技术验证进行中**（当前进度见下方）
> 产品方案：`docs/PRD.md` ｜ 评审报告：`docs/REVIEW.md` ｜ 任务清单：`docs/BACKLOG.md` ｜ 技术决策：`docs/adr/`

## 快速开始

环境要求：Rust ≥ 1.88（推荐 1.92+）。

```bash
cargo run          # 开发模式运行（首次编译 Bevy 需 5-15 分钟）
cargo check        # 快速编译检查
```

### 操作

| 操作 | 说明 |
|------|------|
| 左键点击 | 放置当前积木（点击而非拖拽） |
| 左键拖拽 | 轨道旋转视角 |
| 右键拖拽 | 平移视点 |
| 滚轮 | 缩放 |
| `1`-`9` / `Q` / `E` | 选择积木（或点击左侧面板；当前 30 种，见 `resources/blocks/`） |
| `M` | 切换 蓝图模式 / 自由模式（蓝图模式仅可放置蓝图期望格，完成度进度条实时显示） |
| `T` | 昼夜切换（平滑过渡） |
| `F5` / `F6` / `F9` | 保存 `.ptw` / 导出 JSON / 读取存档 |
| `Backspace` / `Ctrl+Z` / `Ctrl+Y` | 撤销 / 撤销 / 重做（20 步 Command 历史） |
| `N` | 跳过新手教程（启动时自动进入三步引导：台基→红柱→琉璃瓦） |
| `Esc` | 退出 |

## 代码结构

```
src/
├── main.rs                 # 入口：插件注册
├── game_state.rs           # 游戏状态机骨架（Menu / Playing）
├── camera/
│   └── orbit_camera.rs     # 轨道相机系统
├── building/
│   ├── block_defs.rs       # 积木定义加载（RON 数据驱动，B-06）
│   ├── blueprint.rs        # 蓝图：稀疏格子匹配 + 完成度（B-08，含单测）
│   └── placement.rs        # 三维射线放置 + 幽灵预览 + 蓝图模式
├── scene/
│   └── mod.rs              # 主场景：蛇山/长江/昼夜（B-13）
├── save/
│   └── mod.rs              # 本地存档（B-11）：bincode/JSON/迁移链/原子写入
└── ui/
    ├── hud.rs              # HUD 提示（右下角）
    └── block_panel.rs      # egui 积木面板 + 进度条（B-10）
assets/
└── fonts/                  # CJK 子集字体（B-10，289KB）
resources/
├── blocks/                 # 积木定义（15 个 .ron，新增积木只需加文件）
└── blueprints/             # 蓝图定义（占位黄鹤楼 81 格）
docs/
├── PRD.md                  # 产品方案（原文）
├── REVIEW.md               # 评审报告（技术核实 + 产品建议）
├── BACKLOG.md              # 垂直切片任务清单（B-01 ~ B-27）
└── adr/                    # 架构决策记录（6 篇）
```
