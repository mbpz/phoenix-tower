# 黄鹤楼积木：筑梦江城（Phoenix Tower）

基于 **Rust + Bevy 0.19** 的轻量级 3D 积木搭建游戏：以武汉黄鹤楼为主题，玩家通过放置模块化积木**精准复原**、**自由创造**或**挑战重建**这座千年名楼。

> 状态：**Phase 0 技术验证进行中**（当前进度见下方）
> 产品方案：`docs/PRD.md` ｜ 评审报告：`docs/REVIEW.md` ｜ 任务清单：`docs/BACKLOG.md` ｜ 技术决策：`docs/adr/`

## 快速开始

环境要求：Rust ≥ 1.88（推荐 1.92+）。

```bash
cargo run          # 开发模式运行（首次编译 Bevy 需 5-15 分钟）
cargo check        # 快速编译检查
```

### 操作

| 操作 | 说明 |
|------|------|
| 左键点击 | 放置当前积木（点击而非拖拽） |
| 左键拖拽 | 轨道旋转视角 |
| 右键拖拽 | 平移视点 |
| 滚轮 | 缩放 |
| `1`-`9` / `Q` / `E` | 选择积木（当前 15 种，见 `resources/blocks/`） |
| `T` | 昼夜切换（平滑过渡） |
| `Backspace` | 撤销最后一次放置 |
| `Esc` | 退出 |

## 代码结构

```
src/
├── main.rs                 # 入口：插件注册
├── game_state.rs           # 游戏状态机骨架（Menu / Playing）
├── camera/
│   └── orbit_camera.rs     # 轨道相机系统
├── building/
│   ├── block_defs.rs       # 积木定义加载（RON 数据驱动，B-06）
│   └── placement.rs        # 射线放置 + 幽灵预览 + 撤销
├── scene/
│   └── mod.rs              # 主场景：蛇山/长江/昼夜（B-13）
└── ui/
    └── hud.rs              # HUD 提示（当前积木/快捷键）
resources/
└── blocks/                 # 积木定义（15 个 .ron，新增积木只需加文件）
docs/
├── PRD.md                  # 产品方案（原文）
├── REVIEW.md               # 评审报告（技术核实 + 产品建议）
├── BACKLOG.md              # 垂直切片任务清单（B-01 ~ B-27）
└── adr/                    # 架构决策记录（6 篇）
```
